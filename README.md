One razor-sharp line that gets you out of a pointless meeting:

> My Wi-Fi is fine and my camera works. I just value my time more than this agenda does.

No bad wifi, no cat, no dentist — the excuse is brutally honest
instead. The Wi-Fi works, the camera works, and the meeting simply
isn't worth the time. Pure Python stdlib, no network, no secrets.
`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`) and verifies it byte-for-byte against
a self-check gate (1–200 characters, single line). The line is
deterministic: every run writes the same 86 characters, byte for byte.

Built for the [The Funniest Excuse for Skipping a Meeting](https://make.fun/competitions/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163)
competition on [make.fun](https://make.fun).
